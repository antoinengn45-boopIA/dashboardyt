# YT Manager Dashboard

Un tableau de bord personnalisé et sécurisé pour la gestion de ma chaîne YouTube, incluant des outils de planification éditoriale et d'optimisation SEO.

## 🚀 Fonctionnalités
- **Système de Connexion :** Accès sécurisé différencié par rôle (Admin/User).
- **Générateur SEO :** Outil de suivi de longueur de titres pour maximiser l'impact sur YouTube.
- **Planning Éditorial :** Tableau de suivi du statut de production des vidéos (Écriture, Montage, Publié, etc.).
- **Design Cyber :** Interface moderne, sombre et épurée.

## 🛠 Technologies utilisées
- **HTML5** : Structure de l'interface.
- **CSS3** : Design et animations (style moderne "Cyber").
- **JavaScript** : Logique applicative, gestion des rôles et outils dynamiques.
